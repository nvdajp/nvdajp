## 検証手順

### 1. ローカルでのビルド確認

#### 1.1 署名なしビルド（nonCertBuild.pyを使用）
```powershell
# nonCertBuild.pyでビルド
uv run python jptools/nonCertBuild.py source dist launcher
```

**確認項目**:
- ビルドが正常に完了する
- エラーメッセージが表示されない
- `output/`配下に期待されるファイルが生成される

#### 1.2 SCons直接ビルド
```powershell
# SCons直接ビルド
.\scons.bat source dist launcher --all-cores
```

**確認項目**:
- ビルドが正常に完了する
- `jtalkPrep`と`miscdepsjp`が正常に実行される
- エラーメッセージが表示されない

### 2. ローカルでのユニットテスト確認

```powershell
# ユニットテスト実行
.\rununittests.bat
```

**確認項目**:
- すべてのテストが通過する
- 削除したスクリプトへの参照エラーが発生しない

### 3. ローカルでのjpSmokeTest確認

```powershell
# jpSmokeTest実行
.\jptools\runJpSmokeTests.ps1 -Architecture x86
```

**確認項目**:
- テストが正常に実行される
- すべてのテストが通過する

### 4. CIでの動作確認

**確認項目**:
- GitHub ActionsのCIが正常に完了する
- すべてのジョブが成功する
- 削除したスクリプトへの参照エラーが発生しない

### 5. リリースビルド確認（オプション）

```powershell
# certBuild2023.cmdでリリースビルド
.\jptools\certBuild2023.cmd version_build=99999
```

**確認項目**:
- リリースビルドが正常に完了する
- 署名が正常に適用される

## 代替手段

### nonCertBuild系スクリプトの代替

削除したスクリプトの代替手段：

- **`nonCertBuild1.cmd`** → `uv run python jptools/nonCertBuild.py`（`_prep_miscdepsjp()`相当）
- **`nonCertBuild2.cmd`** → `uv run python jptools/nonCertBuild.py source user_docs dist launcher`
- **`nonCertAllBuild.cmd`** → `uv run python jptools/nonCertBuild.py source user_docs dist launcher`

### devbuild系スクリプトの代替

- **`devbuild.cmd`** → `uv run python jptools/nonCertBuild.py` + `scons.bat`
- **`devbuild2024.cmd`** → `uv run python jptools/nonCertBuild.py` + `scons.bat` + `rununittests.bat`

## 問題が発生した場合

1. **ビルドエラー**: `jptools/.cmd-analysis.md`を参照して、削除したスクリプトが本当に使用されていないか再確認
2. **テストエラー**: 削除したスクリプトへの参照が残っていないか確認（`grep`で検索）
3. **CIエラー**: `.github/workflows/testAndPublish.yml`で削除したスクリプトへの参照がないか確認
